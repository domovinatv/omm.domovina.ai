# Ikone

`MaterialSymbolsSharp.woff2` i `.codepoints` su cijeli varijabilni font Material Symbols Sharp
(Google, Apache License 2.0), iz
[google/material-design-icons](https://github.com/google/material-design-icons/tree/master/variablefont).

U developmentu stranice koriste cijeli font (`npm run dev` ga kopira u `public/ikone`). Za
deploy `npm run build` iz `src/` pokupi korištene klase `i-<ime>` i u `dist/client/ikone` zapiše
font samo s tim ikonama. Imena ikona: https://fonts.google.com/icons?icon.style=Sharp
